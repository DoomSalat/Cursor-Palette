# 🏠 Main — preset gallery

## 📦 Gallery — shows all your cursor presets.
- Left-click a preset — apply cursors.
- Right-click a preset — menu (edit, rename, move left/right, download, delete, add to group).
- 🧩 badge — some roles are borrowed from other presets.
- Drag a tile onto another — reorder presets.
- Ctrl+click tiles — select several presets, then pick a color and name at the bottom to create a group. Click the group tile to collapse/expand it as a deck; right-click it for random pick, edit, consolidate, ungroup or delete it.
- Right-click empty space on the board — "Create group" opens a dialog to make an empty group.

## ➕ "Add preset" — create a new preset.
- Drag .cur/.ani files or a folder onto the window.

## 🎨 Grid size — changes gallery cell size.
📏 Cursor size — slider changes system cursor size; applied immediately.

↩️ "Undo" — revert to previous cursor set.
🌙/☀ — toggle dark/light theme.
🌐 — change interface language.
🔍 −/+ — zoom interface in/out.
{img:OpenFolderIcon32} Open-folder toggle — blue = Downloads folder opens after download/export; gray = disabled.
{img:DownloadIcon32} Export — pick presets and save them as a bundle (.cursorpalette, fully re-importable) or a plain ZIP archive (raw cursor files); saved to Downloads.
{img:ImportIcon26} Import — pick a Cursor Palette bundle/archive file (or drop it onto the window) and choose which presets to add.
📄 Click the footer — "About" window.
{img:DownloadIcon32} Bottom-left — update indicator.
- Blue button — new version available, click to download.
