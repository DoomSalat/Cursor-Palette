# 📥 Импорт пресетов

Это окно открывается после выбора файла-пакета Cursor Palette (.cursorpalette) или ZIP-архива — через кнопку «Импорт» или перетаскиванием файла на главное окно. Перетаскивание папки работает так же — оба варианта распознаются независимо от того, ещё в архиве они или уже распакованы, включая Linux-экспорт (тему Xcursor или обычную папку с исходными файлами курсоров) — тема Xcursor автоматически конвертируется обратно в привычные .cur/.ani.

## 🖼️ Плитки — по одной на каждый найденный в файле пресет; кликните, чтобы выбрать/снять выбор (синяя рамка = выбран).
- «Выбрать всё» / «Выбрать ничего» — кнопки сверху.

☑️ «Скрыть существующие» — включён по умолчанию; скрывает пресеты, файлы курсоров которых побайтово совпадают с уже установленным пресетом (размер и настройки масштабирования при сравнении не учитываются). Выключите, чтобы показать все пресеты, включая дубликаты.

☑️ «Общий размер курсора» — при включении появляется слайдер размера; все импортируемые пресеты получат этот единый размер курсора вместо размера, записанного в файле. При выключении для каждого пресета восстановится его собственный размер из файла.

📦 «Импортировать» — добавляет отмеченные пресеты в галерею как новые (с новыми id, поэтому конфликтов с существующими пресетами не будет).

🎨 Цветные плитки групп — выбор плитки группы автоматически выбирает все её пресеты; снятие выбора с одного пресета снимает выбор и с группы. Чтобы группа восстановилась при импорте, должна быть выбрана именно её плитка.

ℹ️ Из файла-пакета и ZIP-архива восстанавливается всё (роли, заблокированные роли, размер курсора, флаг масштаба, режим масштабирования, группы). ZIP-архив также содержит README.txt с инструкцией по установке и папки с исходными файлами курсоров.
