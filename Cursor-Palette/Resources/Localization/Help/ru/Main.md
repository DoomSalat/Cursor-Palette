# 🏠 Главная — галерея пресетов

## 📦 Галерея — показывает все ваши пресеты курсоров.
- ЛКМ по пресету — применить курсоры.
- ПКМ по пресету — меню (изменить, переименовать, переместить влево/вправо, скачать, удалить, добавить в группу).
- Значок 🧩 — часть ролей взята из других пресетов.
- Перетащите плитку на другую — изменить порядок пресетов.
- Ctrl+клик по плиткам — выделить несколько пресетов, затем выбрать цвет и имя внизу, чтобы создать группу. Клик по плитке группы — свернуть/развернуть колоду; ПКМ — изменить, собрать ячейки, разгруппировать или удалить.
- ПКМ по пустому пространству доски — «Создать группу» открывает диалог для создания пустой группы.

## ➕ «Добавить пресет» — создать новый пресет.
- Перетащите .cur/.ani файлы или папку прямо в окно.

## 🎨 Размер сетки — меняет размер ячеек галереи.
📏 Размер курсора — ползунок + «Применить» меняет системный размер.
↩️ «Назад» — откатить к предыдущему набору курсоров.
🌙/☀ — переключить тёмную/светлую тему.
🌐 — сменить язык интерфейса.
🔍 −/+ — масштаб интерфейса.
{img:OpenFolderIcon32} Иконка папки — синяя = папка «Загрузки» открывается после скачивания/экспорта; серая = отключено.
{img:DownloadIcon32} Экспорт — выбрать пресеты и сохранить их файлом (.cursorpalette, полностью импортируется обратно) или обычным ZIP-архивом (исходные файлы курсоров); сохраняется в «Загрузки».
{img:ImportIcon26} Импорт — выбрать файл пакета/архива Cursor Palette (или перетащить его на окно) и отметить, какие пресеты добавить.
📄 Нажмите на футер внизу — окно «О программе».
{img:DownloadIcon32} Внизу слева — индикатор обновлений.
- Синяя кнопка — новая версия доступна, нажмите для скачивания.
- Текст «Версия актуальна» — обновлений нет.
🖱️ ПКМ по плитке «Стандарт» — скачать системные курсоры в «Загрузки» (PNG+GIF или .cur/.ani).
ⓘ Кнопка справа сверху — справка по окну.
