# ✏️ Редактор пресета

## 🎯 Каждый слот — одна роль курсора (стрелка, текст, занято и т.д.).
- Перетащите .cur/.ani файл на слот — роль заполнится.
- 🎯 на слоте — настроить точку опоры (где клик).
- 🖌 на слоте — изменить позицию спрайта и размер холста (графический редактор).
- ✕ на слоте — убрать файл, вернётся системный курсор.
- {img:LockIcon26} на слоте — заблокировать роль (защита от импорта папки и перетаскивания).
- {img:DownloadIcon32} на слоте — скачать курсор в папку «Загрузки» (имя — пресет + роль).
- 🧩 на слоте — взять роль из другого пресета.
- {img:LinkIcon32} — роль взята из другого пресета (связь).
- Значок «авто» — курсор подставляется автоматически.

## 📁 «Выбрать папку» — импортировать все курсоры из папки сразу.
- Файлы сопоставляются с ролями по имени файла.

📝 Введите название пресета внизу.
{img:DownloadIcon32} Слева от имени — скачать весь пресет папкой в «Загрузки».
📏 Ползунок размера — предпросмотр размера курсора в слотах.
💾 «Сохранить» — сохранить пресет в галерею.
