# 📤 Экспорт пресетов

## 🖼️ Плитки — кликните по пресету, чтобы выбрать/снять выбор (синяя рамка = выбран).
- «Выбрать всё» / «Выбрать ничего» — кнопки сверху.

🎨 Цветные плитки групп — клик по плитке группы выбирает/снимает всех её членов. Группа включается в экспорт, только если выбраны все её пресеты.

📝 Имя файла — необязательно; можно ввести своё имя для экспортируемого файла, а если оставить поле пустым — будет использовано имя по умолчанию.

## 🗂️ Файл vs ZIP-архив — две кнопки экспорта создают разные файлы:
- Файл (.cursorpalette) — полная копия: сохраняются все роли, заблокированные роли, размер курсора и флаг масштаба, а роли, взятые из других пресетов, копируются внутрь — файл получается самодостаточным. Группы также сохраняются и восстанавливаются при импорте. Предназначен для полного обратного импорта в это приложение.
- ZIP-архив — по папке на пресет с исходными .cur/.ani файлами, плюс файл cursor-palette.json с полными метаданными (роли, заблокированные роли, размер курсора, флаг масштаба, группы) и README.txt с инструкцией по установке. Можно импортировать обратно в это приложение как файл-пакет, либо использовать вне приложения в других программах.

🐧 Linux — маленькая стрелка «▾» рядом с кнопкой ZIP-архива открывает ещё два формата: тему Xcursor (index.theme + папка cursors, готова к установке в ~/.icons) или те же исходные .cur/.ani файлы без служебных данных. Оба варианта можно перетащить обратно в это приложение позже — как в виде архива, так и уже распакованными; у кнопки скачивания пресета в редакторе есть такая же стрелка для экспорта только текущего редактируемого пресета.

📄 В той же стрелке «▾» есть пункт «Скачать README» — сохраняет только README.txt отдельно (ссылка на приложение и инструкция по установке), без экспорта каких-либо пресетов.
