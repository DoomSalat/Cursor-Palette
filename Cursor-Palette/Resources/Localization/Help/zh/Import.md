# 📥 导入预设

选择 Cursor Palette 包文件 (.cursorpalette) 或 ZIP 压缩包后会打开此窗口——通过导入按钮，或将文件拖到主窗口。拖拽文件夹同样有效——无论是压缩包还是已解压，都能被识别，也包括 Linux 导出格式（Xcursor 主题或仅含原始光标文件的文件夹）——Xcursor 主题会自动转换回普通的 .cur/.ani 光标。

## 🖼️ 卡片 — 文件中找到的每个预设对应一张；点击即可选中/取消选中（蓝色边框 = 已选中）。
- "全选" / "全不选" — 顶部按钮。

☑️ "统一光标大小" — 勾选后会出现大小滑块；所有导入的预设都会使用这一统一的光标大小，而不是文件中保存的大小。取消勾选可恢复每个预设自身在文件中的大小。

📦 "导入" — 将选中的预设作为新预设添加到画廊中（使用新的 id，因此不会与现有预设冲突）。

🎨 彩色分组卡片 — 选中分组卡片会自动选中其所有成员预设；取消选中某个成员也会取消选中该分组。只有分组卡片本身被选中时，该分组才会被重新创建。

ℹ️ 包文件和 ZIP 压缩包都会恢复全部内容（角色、锁定的角色、光标大小、缩放标志、分组）。ZIP 压缩包还包含带有安装说明的 README.txt 和原始光标文件的文件夹。
