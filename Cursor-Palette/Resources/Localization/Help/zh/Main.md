# 🏠 主窗口 — 预设画廊

## 📦 画廊 — 显示所有光标预设。
- 左键点击预设 — 应用光标。
- 右键点击预设 — 菜单（编辑、重命名、左移/右移、下载、删除、添加到分组）。
- 🧩 标记 — 部分角色取自其他预设。
- 将卡片拖到另一张上 — 调整预设顺序。
- Ctrl+点击多张卡片进行多选，然后在底部选择颜色和名称以创建分组。点击分组卡片可折叠/展开为卡组；右键可随机选择、编辑、整理、取消分组或删除。
- 右键点击画板空白处 —"创建分组"打开对话框创建空分组。

## ➕ "添加预设" — 创建新预设。
- 将 .cur/.ani 文件或文件夹拖到窗口中。

## 🎨 网格大小 — 改变画廊单元格大小。
📏 光标大小 — 滑块 + "应用" 改变系统光标大小。
↩️ "返回" — 恢复到上一个光标集。
🌙/☀ — 切换深色/浅色主题。
🌐 — 更改语言。
🔍 −/+ — 界面缩放。
{img:OpenFolderIcon32} 文件夹图标 — 蓝色 = 下载/导出后打开下载文件夹; 灰色 = 已禁用。
{img:DownloadIcon32} 导出 — 选择预设并保存为包文件（.cursorpalette，可完整重新导入）或普通 ZIP 压缩包（原始光标文件）；保存到"下载"文件夹。
{img:ImportIcon26} 导入 — 选择 Cursor Palette 的包/压缩包文件（或拖到窗口上），勾选要添加的预设。
📄 点击页脚 — "关于" 窗口。
{img:DownloadIcon32} 左下角 — 更新指示器。
- 蓝色按钮 — 有新版本可用，点击下载。
- "已是最新" 文字 — 无更新。
🖱️ 右键点击「默认」磁贴 — 下载系统光标到下载文件夹（PNG+GIF 或 .cur/.ani）。
