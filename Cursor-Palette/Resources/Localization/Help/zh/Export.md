# 📤 导出预设

## 🖼️ 卡片 — 点击预设即可选中/取消选中（蓝色边框 = 已选中）。
- "全选" / "全不选" — 顶部按钮。

🎨 彩色分组卡片 — 点击分组卡片可选中/取消选中其所有成员。只有当分组的所有预设都被选中时，该分组才会被包含在导出中。

📝 文件名 — 可选；可以为导出的文件输入自定义名称，留空则使用默认名称。

## 🗂️ 包文件 vs ZIP 压缩包 — 两个导出按钮生成不同的文件:
- 包文件 (.cursorpalette) — 完整副本：保留所有角色、锁定的角色和光标大小，从其他预设借用的角色也会被复制进来，因此文件是自包含的。分组也会被保存并在导入时恢复。用于以后完整地重新导入本应用。
- ZIP 压缩包 — 每个预设一个文件夹，包含原始的 .cur/.ani 文件，另外还有包含完整元数据（角色、锁定的角色、光标大小、分组）的 cursor-palette.json 文件和带有安装说明的 README.txt。可以像包文件一样重新导入本应用，也可以在其他工具中使用。

{img:DownloadIcon32} 两者都会保存到"下载"文件夹，导出后资源管理器会自动打开并选中新文件。
