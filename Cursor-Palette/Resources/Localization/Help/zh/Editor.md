# ✏️ 预设编辑器

## 🎯 每个槽位 — 一个光标角色（箭头、文本、忙碌等）。
- 将 .cur/.ani 文件拖到槽位 — 填充该角色。
- 🎯 槽位上 — 设置热点（点击位置）。
- 🖌 槽位上 — 编辑精灵位置和画布大小（绘图编辑器）。
- ✕ 槽位上 — 移除文件，恢复系统光标。
- {img:LockIcon26} 槽位上 — 锁定角色（防止文件夹导入和拖放覆盖）。
- {img:DownloadIcon32} 槽位上 — 将光标下载到下载文件夹（以预设名+角色命名）。
- 🧩 槽位上 — 从其他预设借用角色。
- {img:LinkIcon32} — 角色借用自其他预设（链接）。
- "默认" 标记 — 光标自动填充。

## 📁 "选择文件夹" — 从文件夹批量导入光标。
- 文件按文件名匹配到角色。

📝 在底部输入预设名称。
✏️ 顶部的"作者"— 设置预设作者。作者会保存到每个导出预设的README中，并在导入时恢复。
{img:DownloadIcon32} 名称左侧 — 将整个预设作为文件夹下载到下载文件夹。
📏 大小滑块 — 设置此预设的光标大小。
{img:ExpandIcon32} 缩放复选框 — 启用后，光标会以最近邻插值缩放到预设大小，保持像素清晰锐利而非模糊。新预设默认启用。
💾 "保存" — 保存预设到画廊（大小和缩放一起保存）。
