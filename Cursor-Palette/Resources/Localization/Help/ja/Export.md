# 📤 プリセットのエクスポート

## 🖼️ タイル — プリセットをクリックすると選択/選択解除できます（青い枠 = 選択中）。
- 「すべて選択」「選択解除」— 上部のボタン。

🎨 色付きグループタイル — グループタイルをクリックすると、そのメンバー全員を選択/選択解除できます。グループがエクスポートに含まれるのは、すべてのプリセットが選択されている場合のみです。

📝 ファイル名 — 任意。エクスポートするファイルの名前を入力するか、空欄のままにしてデフォルトの名前を使用します。

## 🗂️ バンドル vs ZIPアーカイブ — 2つのエクスポートボタンは異なるファイルを作成します:
- バンドル (.cursorpalette) — 完全なコピー。すべてのロール、ロックされたロール、カーソルサイズが保持され、他のプリセットから借用したロールもコピーされるため、ファイル単体で完結します。グループも保存され、インポート時に復元されます。後でこのアプリに完全に再インポートすることを想定しています。
- ZIPアーカイブ — プリセットごとに1つのフォルダに元の .cur/.ani ファイルが入ります。さらに、完全なメタデータ（ロール、ロックされたロール、カーソルサイズ、グループ）を含む cursor-palette.json と、インストール手順の README.txt も同梱されます。バンドルと同様にこのアプリに再インポートできるほか、他のツールでも使用できます。

🐧 Linux — ZIPアーカイブボタン横の小さな「▾」から、さらに2つの形式を選べます: Xcursorテーマ（index.theme + cursorsフォルダー、~/.icons にそのまま配置可能）、または同じ .cur/.ani ファイルを余分なメタデータなしで書き出したもの。どちらも後でこのアプリにドラッグ＆ドロップして戻せます（ZIPのままでも展開済みでも可）。プリセットエディターのダウンロードボタンにも同じ「▾」があり、編集中のプリセットだけをエクスポートできます。

📄 同じ「▾」には「README をダウンロード」もあり、プリセットは書き出さず README.txt だけを単独で保存します（アプリへのリンクとインストール手順）。
