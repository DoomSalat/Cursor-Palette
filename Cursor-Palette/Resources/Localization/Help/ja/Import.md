# 📥 プリセットのインポート

このウィンドウは、Cursor Palette のバンドル (.cursorpalette) または ZIP アーカイブを選択した後に開きます — インポートボタンから、またはファイルをメインウィンドウにドロップして。インポートボタン横の「▾」からはファイルの代わりにフォルダーを開くこともでき、フォルダーのドロップも同様に動作します。どちらも、ZIPのままでも展開済みでも認識され、Linuxエクスポート（Xcursorテーマ、または元のカーソルファイルだけのフォルダー）も含まれます — Xcursorテーマは自動的に通常の .cur/.ani カーソルに変換されます。

## 🖼️ タイル — ファイル内で見つかったプリセットごとに1枚。クリックで選択/選択解除できます（青い枠 = 選択中）。
- 「すべて選択」「選択解除」— 上部のボタン。

☑️ 「統一カーソルサイズ」— オンにするとサイズスライダーが表示され、インポートされるすべてのプリセットにファイルに保存されたサイズの代わりにこの統一されたカーソルサイズが適用されます。オフにすると各プリセット本来のサイズがファイルから復元されます。

📦 「インポート」— 選択したプリセットを新しいプリセットとしてギャラリーに追加します（新しいIDが割り当てられるため、既存のものと衝突しません）。

🎨 色付きグループタイル — グループタイルを選択すると、そのグループのすべてのプリセットが自動的に選択されます。メンバーの選択を解除するとグループの選択も解除されます。グループ自体が再作成されるのは、そのタイル自体が選択されている場合のみです。

ℹ️ バンドルとZIPアーカイブのどちらも、すべて（ロール、ロックされたロール、カーソルサイズ、グループ）を復元します。ZIPアーカイブにはさらに、インストール手順のREADME.txtと、元のカーソルファイルが入ったフォルダが含まれます。
