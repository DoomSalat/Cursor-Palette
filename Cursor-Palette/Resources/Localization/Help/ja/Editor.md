# ✏️ プリセットエディター

## 🎯 各スロット — カーソルロール（矢印、テキスト、処理中など）。
- .cur/.ani ファイルをスロットにドロップ — ロールを埋める。
- 🎯 スロット上 — 基準点（クリック位置）を設定。
- 🖌 スロット上 — スプライトの位置とキャンバスサイズを編集（ペイントエディタ）。
- ✕ スロット上 — ファイルを削除、システムカーソルに戻る。
- {img:LockIcon26} スロット上 — ロールをロック（フォルダインポートとドラッグ&ドロップから保護）。
- {img:DownloadIcon32} スロット上 — カーソルをダウンロードフォルダに保存（プリセット名+ロール名）。
- 🧩 スロット上 — 他のプリセットからロールを借用。
- ✏️ ファイル名の横 — カーソルファイルの名前を変更（拡張子は保持）。フィールドが空の場合、デフォルトのロール名が使用されます。
- {img:LinkIcon32} — ロールは他のプリセットから借用されている（リンク）。
- 「既定」バッジ — カーソルは自動補充。

## 📁 「フォルダを選択」— フォルダからすべてのカーソルを一括インポート。
- ファイルはファイル名でロールに対応付けされます。

📝 下にプリセット名を入力。
✏️ 上部の「作者」— プリセットの作者を設定。作者はエクスポートされる各プリセットのREADMEに保存され、インポート時に復元されます。
{img:DownloadIcon32} 名前の左 — プリセット全体をフォルダとしてダウンロードに保存。
📏 サイズスライダー — このプリセットのカーソルサイズを設定。
{img:ExpandIcon32} スケーリングチェックボックス — 有効にすると、カーソルがプリセットサイズに最近傍補間でスケーリングされ、ピクセルがぼやけず鮮明でシャープに保たれます。新規プリセットではデフォルトで有効。
💾 「保存」— プリセットをギャラリーに保存（サイズとスケーリングは一緒に保存）。
