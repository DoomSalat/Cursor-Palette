# 🏠 メイン — プリセットギャラリー

## 📦 ギャラリー — すべてのカーソルプリセットを表示します。
- 左クリック — カーソルを適用。
- 右クリック — メニュー（編集、名前を変更、左右に移動、ダウンロード、削除、グループに追加）。
- 🧩 バッジ — 一部のロールは他のプリセットから取得。
- タイルを別のタイルにドラッグ — プリセットの順序を変更。
- Ctrl+クリックで複数のタイルを選択し、下部で色と名前を選んでグループを作成。グループタイルをクリックでデッキとして折りたたみ/展開。右クリックでランダム選択、編集、セルをまとめる、グループ解除、削除。
- ボードの空きスペースを右クリック —「グループを作成」で空のグループを作成するダイアログを開く。

## ➕ 「プリセットを追加」— 新しいプリセットを作成。
- .cur/.ani ファイルまたはフォルダをウィンドウにドロップ。

## 🎨 グリッドサイズ — ギャラリーのセルサイズを変更。
📏 カーソルサイズ — スライダーでシステムサイズを変更; すぐに適用されます。
{img:ExpandIcon32} セル上 — スケーリングが有効; カーソルがプリセットサイズにスケーリングされます。
{img:ExpandIcon32} {img:StairIcon24} スケールモード — クリックでスムーズ（{img:ExpandIcon32}）と最近傍（{img:StairIcon24}）を切り替え。最近傍はレトロ/ピクセルアートカーソル用にシャープなピクセルを保持します。
↩️ 「戻る」— 前のカーソルセットに戻す。
🌙/☀ — ダーク/ライトテーマを切り替え。
🌐 — 言語を変更。
🔍 −/+ — インターフェースのズーム。
{img:OpenFolderIcon32} フォルダアイコン — 青 = ダウンロード/エクスポート後にダウンロードフォルダを開く; 灰 = 無効。
{img:DownloadIcon32} エクスポート — プリセットを選んでバンドル（.cursorpalette、完全に再インポート可能）または通常のZIPアーカイブ（元のカーソルファイル）として保存。ダウンロードフォルダに保存されます。
{img:ImportIcon26} インポート — Cursor Palette のバンドル/アーカイブファイルを選択（またはウィンドウにドロップ）し、追加するプリセットを選びます。
📄 フッターをクリック — 「このアプリについて」ウィンドウ。
{img:DownloadIcon32} 左下 — アップデートインジケーター。
- 青いボタン — 新しいバージョンが利用可能、クリックでダウンロード。
- 「最新です」テキスト — 更新なし。
🖱️「標準」タイルを右クリック — システムカーソルをダウンロードフォルダにダウンロード（PNG+GIF または .cur/.ani）。
ⓘ 右上のボタン — ウィンドウヘルプ。
🖱️ アプリ名の青いカーソルアイコンをクリック — ボード全体からランダムにカーソルを適用。
