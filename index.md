# Cursor Palette — статус фич

> Проект реализован под именем **Cursor Palette** (`Cursor-Palette/`,
> namespace `CursorPalette`).

## Готово (MVP)

- Галерея пресетов с ячейкой "Windows по умолчанию", клик = применение
- Импорт `.cur/.ani` россыпью и папкой через drag&drop + диалог выбора
- Редактор пресета (слоты-роли, автораспознавание по имени, ручная замена)
- Удаление пресета с подтверждением
- Кнопка "Отменить последнее изменение" (снимок предыдущего состояния)
- Слайдер размера курсора — применяется и сохраняется отдельно на каждый
  пресет + дублирующий ползунок в редакторе, синхронизирован с главным
- Портативный self-contained `.exe`, иконка приложения, окно "О программе",
  ссылка на GitHub в футере

## v1.1.0

- Светлая/тёмная тема с тумблером в шапке — при первом запуске читает
  системную тему Windows, дальше запоминает выбор
- Зум всего интерфейса (VSCode-style), сохраняется между запусками
- Ползунок размера ячеек галереи (50–350%)
- Кастомный тонкий скроллбар

## v1.1.1

- Локализация — переключатель языка в шапке (RU/EN/zh/ja/es/de), при первом
  запуске подхватывает системный язык, дальше запоминает выбор. Добавление
  нового языка — только новый файл ресурсов, без изменения кода
- Анимированные `.ani`-курсоры в превью проигрывают все кадры по оригинальным
  таймингам вместо статичного первого кадра
- Редактор точки опоры (pivot/hotspot) — увеличенное превью с перетаскиваемым
  маркером + джойстик 3×3 для быстрой установки в угол/край/центр. Работает
  для `.cur` и для всех кадров `.ani`
- Импорт из архивов (`.zip`/`.rar`/`.7z`) — drag&drop архива работает везде,
  где работала папка: на главное окно и в зону "Choose folder" редактора
- Визуальная реакция на перетаскивание — синий пунктирный контур появляется
  на зоне, куда можно бросить файл, с проверкой типа содержимого
- Имя нового пресета подхватывается из папки/архива при дропе на главное окно
- Пустые слоты в редакторе показывают дефолтный курсор роли (полупрозрачно +
  бейдж "авто")
- Вшитые файлы-заглушки для ролей Crosshair/IBeam (Windows не хранит для них
  отдельные `.cur`)
- Автораспознавание роли по отдельным словам в имени файла (не только точное
  совпадение)
- Затемнение экрана + спиннер на время применения курсора
- Кнопка "Применить" (размер курсора) подсвечивается, когда ползунок
  отличается от применённого значения
- Кнопка "✕" (убрать роль) подсвечивается красным при наведении
- Кастомные стили контекстного меню под тему
- Тултип на ячейке пресета ("ПКМ — меню")

## v1.2.2

- **Перетаскивание плиток пресетов для сортировки** — на главном экране можно
  менять порядок пресетов drag&drop'ом:
  - при перетаскивании под курсором летит полупрозрачная копия плитки
    (превью + название)
  - между ячейками показывается синяя полоска-индикатор, куда именно попадёт
    плитка при отпускании (по аналогии с сортировкой иконок на смартфоне)
  - индикатор не показывается, если бросок ничего не изменит (та же позиция)
  - порядок сохраняется отдельным полем `SortOrder` в манифесте пресета и
    переживает перезапуск приложения

## v1.3.0

- **Экспорт/импорт пресетов** — кнопки в нижней панели рядом с зумом:
  - Экспорт открывает окно с плиточной сеткой всех пресетов (превью,
    название, счётчик ролей — по аналогии с главной галереей): клик по
    плитке выбирает/снимает выбор, выбранное подсвечивается синей рамкой,
    плюс кнопки "Выбрать всё"/"Выбрать ничего". Два независимых действия:
    - **Экспорт файла** (`.cursorpalette`) — полнофункциональный пакет
      (роли, заблокированные роли, размер курсора); ссылочные роли
      разворачиваются в реальные файлы, так что каждый пресет в пакете
      самодостаточен
    - **Экспорт как ZIP-архив** — по папке на пресет с исходными
      `.cur`/`.ani` файлами, для использования вне приложения
    - оба варианта сохраняются в "Загрузки", после чего автоматически
      открывается проводник с выделенным файлом
  - Импорт — кнопка с диалогом выбора файла или перетаскивание
    экспортированного файла/архива на главное окно. Оба формата помечены
    внутренним маркером, поэтому drag&drop отличает их от обычных
    курсор-файлов/архивов и не путает с созданием нового пресета
  - После выбора файла открывается такое же плиточное окно со списком
    найденных пресетов (превью, синяя рамка = выбран, "Выбрать
    всё"/"Выбрать ничего") — импортируются только отмеченные, каждый как
    новый пресет с новым id
  - В обоих окнах — кнопка ⓘ со справкой: описание плиток/выбора и отдельный
    блок про разницу между файлом-пакетом и ZIP-архивом
- Фикс: в окнах справки (ⓘ) длинные строки-буллеты (`•`) обрезались вместо
  переноса на новую строку — `TextBlock` внутри горизонтального `StackPanel`
  получал бесконечную ширину и не мог переноситься; заменено на `Grid` с
  колонкой-звёздочкой под текст (как уже было сделано для строк с иконками)
- Блок проверки обновлений в шапке доработан:
  - во время проверки рядом со спиннером показывается текст "Проверка версии"
  - надпись "Версия актуальна" получила серую галочку ✓ перед текстом (цвет
    в тон тексту)
  - клик по "Версия актуальна" запускает проверку обновлений заново вручную
