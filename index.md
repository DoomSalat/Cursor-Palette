# Cursor Palette — статус фич

> Проект реализован под именем **Cursor Palette** (`Cursor-Palette/`,
> namespace `CursorPalette`).

## Готово (MVP)

- Галерея пресетов с ячейкой "Windows по умолчанию", клик = применение
- Импорт `.cur/.ani` россыпью и папкой через drag&drop + диалог выбора
- Редактор пресета (слоты-роли, автораспознавание по имени, ручная замена)
- Удаление пресета с подтверждением
- Кнопка "Отменить последнее изменение" (снимок предыдущего состояния)
- Слайдер размера курсора — применяется и сохраняется отдельно на каждый
  пресет + дублирующий ползунок в редакторе, синхронизирован с главным
- Портативный self-contained `.exe`, иконка приложения, окно "О программе",
  ссылка на GitHub в футере

## v1.3.0

- **Экспорт/импорт пресетов** — кнопки в нижней панели рядом с зумом:
  - Экспорт открывает окно с плиточной сеткой всех пресетов (превью,
    название, счётчик ролей — по аналогии с главной галереей): клик по
    плитке выбирает/снимает выбор, выбранное подсвечивается синей рамкой,
    плюс кнопки "Выбрать всё"/"Выбрать ничего". Два независимых действия:
    - **Экспорт файла** (`.cursorpalette`) — полнофункциональный пакет
      (роли, заблокированные роли, размер курсора); ссылочные роли
      разворачиваются в реальные файлы, так что каждый пресет в пакете
      самодостаточен
    - **Экспорт как ZIP-архив** — по папке на пресет с исходными
      `.cur`/`.ani` файлами, для использования вне приложения
    - оба варианта сохраняются в "Загрузки", после чего автоматически
      открывается проводник с выделенным файлом
  - Импорт — кнопка с диалогом выбора файла или перетаскивание
    экспортированного файла/архива на главное окно. Оба формата помечены
    внутренним маркером, поэтому drag&drop отличает их от обычных
    курсор-файлов/архивов и не путает с созданием нового пресета
  - После выбора файла открывается такое же плиточное окно со списком
    найденных пресетов (превью, синяя рамка = выбран, "Выбрать
    всё"/"Выбрать ничего") — импортируются только отмеченные, каждый как
    новый пресет с новым id
  - В обоих окнах — кнопка ⓘ со справкой: описание плиток/выбора и отдельный
    блок про разницу между файлом-пакетом и ZIP-архивом
  - Защита от несовместимых пакетов — маркер-файл внутри пакета несёт номер
    версии формата; если он старше, чем понимает установленная версия
    приложения, импорт прерывается понятной ошибкой ("нужна более новая
    версия Cursor Palette") вместо попытки распарсить незнакомую структуру.
    При перетаскивании такой пакет на главное окно ошибка тоже показывается
    явно, а не тихо откатывается на создание нового пресета из файлов
  - Поле "Имя файла" в окне экспорта — необязательное; если оставить пустым,
    используется прежнее стандартное имя (`Cursor Palette Presets`), иначе —
    введённое имя (санитизируется под файловую систему)
  - Галочка "Игнорировать размеры отдельных пресетов" в окне импорта — при
    включении показывает слайдер общего размера (тот же диапазон/шаг, что и
    везде в приложении); все выбранные к импорту пресеты получают этот единый
    размер вместо значения, сохранённого в файле. Выключение галочки
    восстанавливает прежнее поведение — размер каждого пресета берётся из
    файла
- Фикс: кнопка экспорта открывала в проводнике папку "Документы" вместо
  "Загрузок" — `explorer.exe /select,"путь"` передавался через `ArgumentList`
  (который сам экранирует аргумент), из-за чего ручные кавычки задваивались и
  explorer не мог распознать путь; заменено на `Arguments`-строку
- Фикс: в окнах справки (ⓘ) длинные строки-буллеты (`•`) обрезались вместо
  переноса на новую строку — `TextBlock` внутри горизонтального `StackPanel`
  получал бесконечную ширину и не мог переноситься; заменено на `Grid` с
  колонкой-звёздочкой под текст (как уже было сделано для строк с иконками)
- Блок проверки обновлений в шапке доработан:
  - во время проверки рядом со спиннером показывается текст "Проверка версии"
  - надпись "Версия актуальна" получила серую галочку ✓ перед текстом (цвет
    в тон тексту)
  - клик по "Версия актуальна" запускает проверку обновлений заново вручную

## v2.0.0

- **Paint editor** (переименован из PositionEditor) — редактирование позиции
  спрайта и размера холста курсора, открывается кнопкой на слоте в редакторе
  пресета:
  - Инструменты в шапке: **Move** (перетаскивание спрайта + стрелки/джойстик
    "прижать к краю"), **Hand** (панорамирование зажатой левой кнопкой),
    **Canvas** (визуальная растяжка холста за края/углы), плюс заглушки
    Brush/Eraser ("скоро") с новыми иконками (карандаш, ластик) вместо эмодзи
  - Панорамирование холста средней кнопкой мыши работает всегда, независимо
    от активного инструмента (как в Aseprite); реализовано через свободный
    Translate+Scale-вьюпорт вместо `ScrollViewer`, поэтому работает и когда
    холст целиком помещается в окно
  - Зум колесом мыши (Ctrl) и кнопками +/- теперь центрируется относительно
    курсора/центра вьюпорта, а не "прыгает"
  - Инструмент **Canvas**: рамка и ручки растяжки холста показываются только
    пока инструмент активен; размер применяется как live-превью и
    подтверждается кнопкой "Применить" — переключение на другой инструмент
    без подтверждения откатывает холст к прежнему размеру/позиции
  - Диалог "Canvas size": стал resizable (раньше был фиксированного размера
    и обрезал контент), пресет-дропдаун переведён на тему приложения, у
    сетки "Привязка" появились иконки-стрелки как у джойстика Move, и
    исправлена инвертированная математика привязки (например клик по
    центру раньше уводил спрайт в угол)
  - Экспорт `.png` теперь называет файл по шаблону "Имя пресета + роль
    курсора + размер" (например `Мой пресет Arrow 32x32.png`) вместо
    generic `cursor_32x32.png`, используя тот же список ролей, что и
    автораспознавание по имени файла
  - Увеличены элементы интерфейса (кнопки инструментов, боковая панель,
    нижняя панель) — раньше были слишком мелкими, особенно на маленьких
    холстах (32×32 и меньше)
  - Оверлей растяжки холста (рамка, ручки, подпись размера) теперь
    масштабируется обратно пропорционально зуму холста, чтобы не раздуваться
    до огромного размера при сильном приближении
  - Исправлена низкая чувствительность перетаскивания спрайта (Move) и ручек
    растяжки холста (Canvas) — координаты делились на масштаб холста дважды
  - Исправлено некорректное поведение ручек растяжки холста при быстром
    перетаскивании (в т.ч. "уезжание" в отрицательные значения) — `Thumb.
    DragDelta` даёт дельту с прошлого события, а не с начала перетаскивания,
    код ошибочно считал её накопительной

## v2.0.3

- **Группы пресетов на доске** — Ctrl+клик по плиткам выделяет несколько
  пресетов, затем выбор цвета и имени внизу создаёт группу:
  - клик по плитке группы — свернуть/развернуть колоду (collapsed mode
    показывает плитки внахлёст, expanded — рядом как обычно)
  - ПКМ по группе — изменить (диалог с именем и цветом), «собрать ячейки
    вместе», разгруппировать (вытащить все пресеты, группа остаётся пустой)
    или удалить группу (вместе со всеми пресетами-членами)
  - ПКМ по пустому пространству доски — «Создать группу» открывает диалог
    для создания пустой группы
  - ПКМ по пресету — подменю «Добавить в группу» со списком всех групп
    (с цветными значками); пресет можно переместить из одной группы в другую
  - перетаскивание плитки на группу (наведение на центральную зону) —
    присоединить пресет к группе; пунктирный контур показывает целевую группу
  - порядок доски сохраняется и переживает перезапуск
- **Группы в экспорте/импорте** — окно экспорта теперь показывает цветные
  плитки групп; клик по группе выбирает/снимает всех её членов. Группа
  включается в `.cursorpalette`-файл, только если выбраны все её пресеты.
  При импорте группы восстанавливаются автоматически
- Фикс: Y-позиция индикатора перетаскивания при reorder — определение строки
  по containment вместо расстояния до центра, высота индикатора по реальной
  высоте строки
- Фикс: Y-позиция пунктирного контура группы при наведении — отдельная логика
  для свёрнутого и развёрнутого состояния
- Фикс: подменю MenuItem не отображалось из-за отсутствия ItemsPresenter
  и Popup в кастомном ControlTemplate (Dark/Light темы)
- Toast-уведомления при «Собрать ячейки вместе», «Разгруппировать» и
  «Удалить группу»

## v2.1.0

- **Рисование в Paint editor** — инструменты Brush, Eraser и Fill вместо
  заглушек "скоро":
  - Brush/Eraser рисуют по пикселям зажатой левой кнопкой мыши, белый
    контур показывает пиксель под курсором
  - Shift+клик рисует прямую линию от последней точки (как в Aseprite),
    Shift+Ctrl — с привязкой к шагам 45°; работает и для Eraser
  - Fill — клик по области одного цвета заливает её выбранным цветом
  - Выбор цвета — переключатель ◐/■ между колесом и Photoshop-style
    квадратом (шкала оттенка становится градиентной полосой), яркость и
    альфа — ползунками, шестнадцатеричный код можно скопировать/вставить
    вручную
  - Пипетка (Eyedropper) — кнопка над палитрой или Alt+клик при активном
    Brush/Fill берёт цвет с любой точки экрана, а не только с холста;
    подсвечивается синим и меняет курсор, пока активна, Esc отменяет
  - Undo/Redo (Ctrl+Z / Ctrl+Y или Ctrl+Shift+Z) — история изменений
    покрывает рисование, ластик, заливку, перемещение спрайта, изменение
    холста и импорт изображений
  - Инструмент Hotspot внутри Paint editor заработал по-настоящему —
    перетаскивание маркера или клик по нужной точке + 9 кнопок быстрой
    установки (углы/края/центр) — раньше был заглушкой "скоро"
  - Между запусками теперь сохраняются последний инструмент, зум, позиция
    панорамирования, цвет и режим палитры (колесо/квадрат)
  - У инструментов появились горячие клавиши: V/H/B/E/G/C/O
- **Фоновая подложка для обводки (Background Ref)** — новый инструмент
  показывает полупрозрачную картинку позади спрайта курсора:
  - непрозрачность, отступ и смещение от центра настраиваются ползунками
  - своя картинка — через "Load PNG…" или drag&drop прямо на холст
  - "Reset to role default" / "Reset settings" возвращают дефолтную
    подложку для роли или сбрасывают все настройки
  - подложка не сохраняется в сам курсор — только вспомогательный слой
- **Импорт изображения на холст** — кнопка "Load image" (или drag&drop
  файла на холст: `.png/.jpg/.jpeg/.bmp/.gif`, а также `.cur/.ani` — берётся
  первый кадр) открывает диалог с выбором режима:
  - **Over** — накладывает картинку поверх текущего спрайта с
    альфа-смешиванием, холст расширяется, если картинка больше
  - **Replace** — полностью заменяет содержимое холста импортированной
    картинкой (с учётом лимитов мин/макс размера холста)
- Кнопка Paint editor теперь доступна и для пустых слотов пресета — можно
  нарисовать курсор с нуля на пустом холсте 32×32, не подкладывая файл
- Фикс: подсветка зоны для перетаскивания (drop-zone) не гасла при переходе
  курсора между главным окном и модальным окном поверх него (Paint editor,
  редактор пресета) — модальные окна, открытые через `ShowDialog()`,
  отключают владельца, из-за чего Windows не присылает DragLeave/DragEnter
  при пересечении курсором границы между ними; вместо разового
  `WindowFromPoint`-чека добавлен опрашивающий watchdog (`DropZoneService`),
  который сам отслеживает выход курсора за пределы окна
- Фикс: мерцание холста во время рисования — превью-`WriteableBitmap`
  пересоздавался на каждый мазок вместо переиспользования
- Фикс: привязка линии к 45° иногда сдваивала пиксель из-за ошибки на
  единицу в округлении угла

## v2.2.0

- **Экспорт для Linux** — рядом с кнопкой "Экспортировать как ZIP-архив" (в
  окне экспорта и в кнопке скачивания пресета внутри редактора) появилась
  стрелка "▾" с двумя новыми форматами:
  - **Xcursor theme** — настоящая конвертация: пишет бинарный формат Xcursor
    (магическое число, TOC, premultiplied ARGB32) и раскладывает по папке
    `cursors/` с `index.theme`; каждая из 17 ролей Windows сопоставлена с
    несколькими Xcursor/CSS-именами (`left_ptr`, `text`, `ns-resize`,
    `pointer`, `fleur` и т.д.), поскольку символьные ссылки из
    Windows-архива ненадёжны — вместо них копия файла на каждый алиас.
    Анимация (`.ani`) переносится как несколько кадров в одном
    Xcursor-файле с исходными задержками
  - **Raw cursor files** — прежний вариант без конвертации: просто папка(и)
    с исходными `.cur`/`.ani`, без служебных файлов
  - Оба варианта в окне экспорта работают сразу для нескольких выбранных
    пресетов; вариант в редакторе — только для текущего редактируемого
    пресета (включая ещё не сохранённые изменения — читает прямо из слотов)
  - Имя итогового Xcursor-архива всегда получает суффикс "(Xcursor)",
    независимо от того, введено ли своё имя в окне экспорта
- **Обратная совместимость** — оба Linux-формата можно перетащить обратно в
  приложение:
  - `PresetPackageService.TryDetectPackage` научился распознавать архив без
    JSON-маркера как набор папок-пресетов (по наличию `.cur`/`.ani` внутри
    подпапок) или как Xcursor-тему (по наличию `cursors/` + `index.theme`);
    в последнем случае бинарные файлы разбираются обратно в кадры
    (депремультипликация альфы) и пересобираются в `.cur`/`.ani`
  - Тот же детект теперь работает не только с архивом-файлом, но и с голой
    папкой — `TryDetectPackageFromFolder` копирует её во временную директорию
    и прогоняет через общую логику, не трогая исходную папку пользователя
  - Кнопка "Импорт" получила стрелку "▾" с пунктом "Импортировать папку…"
    (`OpenFolderDialog`, .NET 8); drag&drop папки на главное окно тоже
    пробует её как пакет, прежде чем открывать редактор для одиночных файлов
  - В окне редактора пресета drag&drop Xcursor-темы (файлы без расширения)
    отдельно распознаётся и раскладывается по слотам по ролям — обычное
    сканирование по расширению файла для них не подходит
- Экспорт для Linux не требует Linux — всё генерируется на Windows по
  документированному бинарному формату Xcursor, без внешних инструментов
  вроде `xcursorgen`

## Следующее

- Полная поддержка Linux — нативная сборка и запуск приложения под Linux
  (WPF → Avalonia или аналогичный кросс-платформенный фреймворк), применение
  курсоров через Xcursor вместо Win32 API, адаптация путей и диалогов под
  Linux-окружение
