# Cursor Palette — статус фич

> Проект реализован под именем **Cursor Palette** (`Cursor-Palette/`,
> namespace `CursorPalette`).

## Готово (MVP)

- Галерея пресетов с ячейкой "Windows по умолчанию", клик = применение
- Импорт `.cur/.ani` россыпью и папкой через drag&drop + диалог выбора
- Редактор пресета (слоты-роли, автораспознавание по имени, ручная замена)
- Удаление пресета с подтверждением
- Кнопка "Отменить последнее изменение" (снимок предыдущего состояния)
- Слайдер размера курсора — применяется и сохраняется отдельно на каждый
  пресет + дублирующий ползунок в редакторе, синхронизирован с главным
- Портативный self-contained `.exe`, иконка приложения, окно "О программе",
  ссылка на GitHub в футере

## v1.1.0

- Светлая/тёмная тема с тумблером в шапке — при первом запуске читает
  системную тему Windows, дальше запоминает выбор
- Зум всего интерфейса (VSCode-style), сохраняется между запусками
- Ползунок размера ячеек галереи (50–350%)
- Кастомный тонкий скроллбар

## v1.1.1

- Локализация — переключатель языка в шапке (RU/EN/zh/ja/es/de), при первом
  запуске подхватывает системный язык, дальше запоминает выбор. Добавление
  нового языка — только новый файл ресурсов, без изменения кода
- Анимированные `.ani`-курсоры в превью проигрывают все кадры по оригинальным
  таймингам вместо статичного первого кадра
- Редактор точки опоры (pivot/hotspot) — увеличенное превью с перетаскиваемым
  маркером + джойстик 3×3 для быстрой установки в угол/край/центр. Работает
  для `.cur` и для всех кадров `.ani`
- Импорт из архивов (`.zip`/`.rar`/`.7z`) — drag&drop архива работает везде,
  где работала папка: на главное окно и в зону "Choose folder" редактора
- Визуальная реакция на перетаскивание — синий пунктирный контур появляется
  на зоне, куда можно бросить файл, с проверкой типа содержимого
- Имя нового пресета подхватывается из папки/архива при дропе на главное окно
- Пустые слоты в редакторе показывают дефолтный курсор роли (полупрозрачно +
  бейдж "авто")
- Вшитые файлы-заглушки для ролей Crosshair/IBeam (Windows не хранит для них
  отдельные `.cur`)
- Автораспознавание роли по отдельным словам в имени файла (не только точное
  совпадение)
- Затемнение экрана + спиннер на время применения курсора
- Кнопка "Применить" (размер курсора) подсвечивается, когда ползунок
  отличается от применённого значения
- Кнопка "✕" (убрать роль) подсвечивается красным при наведении
- Кастомные стили контекстного меню под тему
- Тултип на ячейке пресета ("ПКМ — меню")

## v1.1.2

- **Микс ролей из существующих пресетов** — любой слот в редакторе может
  взять роль из другого сохранённого пресета вместо файла с диска:
  - двухшаговый picker: выбор пресета-источника → выбор роли
  - тумблер "только текущая роль" (по умолчанию включён)
  - пресет со ссылочными ролями помечается значком 🧩 в галерее
  - на слоте — иконка-цепочка с тултипом, показывающим источник ссылки
  - правка точки опоры на ссылочном слоте автоматически отвязывает роль
    в собственную копию файла
- Фикс: счётчик ролей на ячейке пресета учитывал только собственные файлы,
  не роли-ссылки
- Фикс: сохранение в редакторе не обновляло галерею при редактировании
  активного пресета
- **Рефакторинг кода:**
  - Переименование сокращённых переменных во всех C#-файлах до описательных
    имён
  - Константы Win32 API приведены к PascalCase
  - Строковые литералы ресурсных ключей вынесены в константы во всех
    View-файлах
  - Добавлен ресурс `GridSquaresIcon32.png` для будущего использования

## Отложено

- Экспорт/импорт пресетов — поделиться пресетом с другим человеком

  фонового low-level хука, принципиально другой механизм
