# 🖌️ 绘图编辑器

在画布内移动光标图像、调整画布大小、绘制像素，或平移和缩放视图。

🧰 工具（顶部栏）：
✥ 移动 — 直接拖动图像，或使用箭头/贴靠网格。
✋ 抓手 — 按住鼠标左键拖动即可平移画布。鼠标中键在任何工具下都可以平移。
{img:PencilIcon48} 画笔 — 按住鼠标左键绘制像素。光标下的像素会显示白色轮廓。按住 Shift 点击可从上一个点绘制一条直线；再按住 Ctrl 可将角度吸附到 45° 的倍数。在右侧选择颜色 — 右上角的 ◐/■ 切换按钮可在色轮和仿 Photoshop 方形取色器之间切换，调整色相/亮度和不透明度，或直接输入/粘贴十六进制颜色代码。
{img:EraseIcon32} 橡皮擦 — 按住鼠标左键擦除像素（使其透明）。Shift 和 Shift+Ctrl 的用法与画笔相同，可绘制直线擦除。
{img:FillIcon32} 填充 — 点击同一颜色的区域，用选定的颜色填充。使用与画笔相同的色轮。
{img:EyedropperIcon48} 取色器 — 点击取色面板上方的按钮，或在使用画笔/填充时按住 Alt 点击，即可从屏幕上任意位置取色。取色器激活时按钮会变蓝，光标也会改变；按 Esc 可取消。
⛶ 画布 — 拖动画布边缘/角落的控制点调整大小，然后点击"应用"确认。未确认就切换到其他工具会撤销更改。
🎯 热点 — 拖动画布上的标记，或点击目标位置；9 个快速设置按钮可跳转到典型位置（角落、边缘、中心）。
{img:ImageRefIcon32} 参考图 — 在光标精灵背后显示参考图片用于描摹。调整不透明度、边距、偏移和双线性过滤，或拖放自己的图片。"隐藏主图像"可临时隐藏正在绘制的图案，只显示参考图。如果参考图是动画的，在联动模式下其帧会跟随时间轴的活动帧；启用"手动控制参考帧"可用 ◀/▶/⟲ 独立浏览其帧。不会保存到光标中。
↶ 撤销 — 撤销上一次更改 (Ctrl+Z)。
↷ 重做 — 重新应用已撤销的更改 (Ctrl+Y 或 Ctrl+Shift+Z)。

🎞️ 动画时间轴（画布下方的栏）— "+"/"−" 添加或删除帧，帧编号切换当前活动帧。▶/⏹ 播放/停止预览；"毫秒"输入框设置活动帧的持续时间。"应用于全部"将该持续时间一次性应用到所有帧；取消勾选可恢复之前各帧的独立值。"手动控制参考帧"可将参考图与时间轴分离，独立浏览。限制 — 最多60帧，每帧最短17毫秒（.ani格式限制）。
{img:DownloadIcon32} ".gif"（在".png"旁边）— 当帧数大于1时出现，将动画导出为GIF到下载文件夹。导出画布上当前尺寸的精确内容（包括子尺寸预览）。

🕹️ 箭头（移动工具）— 将图像移动1像素；当图像到达该边缘时按钮会禁用。
⚡ 贴靠网格（移动工具）— 9个按钮，可将图像贴到边缘/角落或居中。
📐 "画布大小"（右上角）— 设置精确的宽度/高度，选择预设，并选择画布放大或缩小时的锚点。
{img:DownloadIcon32} "加载图像"（右上角）— 通过文件选择器加载 .png/.jpg/.bmp/.gif 或 .cur/.ani（取第一帧；动画GIF会整体导入为帧时间轴），也可拖到按钮/画布上；选择"叠加"将图像合成到当前精灵上（画布会扩展以适应图像大小），或选择"替换"完全替换画布内容。在当前画布尺寸下工作 — 打开子尺寸预览并加载图像，将其直接应用到该子尺寸，然后点击"保存"以保留。

🔍 缩放 — Ctrl + 鼠标滚轮，或 −/+ 按钮，以光标为中心缩放。另一组 −/+ 用于缩放编辑器界面。
☑️ "精灵边界" — 勾勒图像不透明像素的轮廓。
{img:DownloadIcon32} ".png" — 将画布导出为 PNG 到下载文件夹（以预设名+角色+尺寸命名）。导出画布上当前尺寸的精确内容（包括子尺寸预览）。

坐标显示在左下角。
💾 "保存" — 应用更改。

🔄 上次的工具、缩放、位置、颜色和取色器模式会在会话之间保存。右侧工具面板的宽度也会保存 — 拖动分隔条即可调整。
