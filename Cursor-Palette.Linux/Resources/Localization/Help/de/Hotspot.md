# 🎯 Ankerpunkt-Editor

Der Ankerpunkt ist die Position, an der der Klick registriert wird.

## 🖱️ Marker (Kreis) auf dem Cursor-Bild ziehen.
- Oder auf die gewünschte Stelle im Vorschaubild klicken.

## ⚡ Schnellauswahl — 9 Schaltflächen mit typischen Positionen:
↖ ↑ ↗   — obere Reihe
← ✛ →   — mittlere Reihe (✛ = Mitte)
↙ ↓ ↘   — untere Reihe

Koordinaten unten links angezeigt.
💾 "Speichern" — Ankerpunkt anwenden.
