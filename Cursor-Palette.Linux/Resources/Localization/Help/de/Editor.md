# ✏️ Preset-Editor

## 🎯 Jeder Platz — eine Cursor-Rolle (Pfeil, Text, Beschäftigt usw.).
- .cur/.ani-Datei auf Platz ziehen — Rolle füllen.
- 🎯 auf Platz — Ankerpunkt (Klickposition) festlegen.
- 🖌 auf Platz — Sprite-Position und Leinwandgröße bearbeiten (Mal-Editor).
- ✕ auf Platz — Datei entfernen, Systemcursor zurück.
- {img:LockIcon26} auf Platz — Rolle sperren (Schutz vor Ordnerimport und Drag-and-Drop).
- {img:DownloadIcon32} auf Platz — Cursor in den Downloads-Ordner herunterladen (benannt nach Preset + Rolle).
- 🧩 auf Platz — Rolle aus anderem Preset übernehmen.
- {img:LinkIcon32} — Rolle stammt aus einem anderen Preset (Verknüpfung).
- "auto" Symbol — Cursor wird automatisch eingesetzt.

## 📁 "Ordner wählen" — alle Cursor aus einem Ordner importieren.
- Dateien werden nach Dateiname Rollen zugeordnet.

📝 Preset-Namen unten eingeben.
{img:DownloadIcon32} Links vom Namen — das gesamte Preset als Ordner in die Downloads herunterladen.
📏 Größenregler — Cursorgröße in Plätzen vorschauen.
💾 "Speichern" — Preset in Galerie speichern.
